Chat Groq em Python
Chat simples desenvolvido em Python utilizando a API Groq.

Requisitos
Python 3
groq
python-dotenv
Instalação
pip install groq
pip install python-dotenv
Configuração
Crie um arquivo .env:

GROQ_API_KEY=sua_chave_aqui
Execução
python app.py
Funcionalidades
Envia perguntas para a API Groq
Recebe respostas da IA
Carrega a chave da API usando variáveis de ambiente `
